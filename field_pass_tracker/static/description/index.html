GRA — Gov Relation Assistance

Field Pass & Document Compliance Tracker for Oilfield Operations

Odoo 16 | OPL-1

Overview

GRA is a comprehensive compliance management module designed for oilfield operations. It tracks employee and vehicle field passes, document expiry dates, and renewal workflows — all integrated within Odoo. Eliminate double data entry, enforce prerequisites, and get instant visibility into your team's compliance status.

🎫

Field Pass Tracking

Track KOC, RATQA, Wafra, Fawares, and Temp passes for employees and vehicles with real-time status.

📄

Document Management

Monitor passport, residency, civil ID, driving license, PTW, and vehicle documents with expiry alerts.

🔄

Renewal Workflows

Event-log based renewal and application wizards with submit, reject, and issue tracking per record.

📊

Smart Dashboard

4-tab dashboard showing field passes, documents, progress pipeline, and employee statistics.

🔒

Prerequisites Enforcement

Hard blocks prevent out-of-order processing — Driving Authority requires HSE Training, PTW requires KOC Pass.

👥

3-Level Security

Viewer, Admin, and Manager roles with granular access control over records, renewals, and administration.

📈

Processing Statistics

Average processing time by document type, pass type, and nationality for operational insights.

🚗

Vehicle Compliance

Full vehicle document chain: Registration → 3rd Party Inspection → Clearance Certificate with prerequisites.

🌐

Bilingual UI

Full Arabic and English interface throughout — labels, status badges, and menu items in both languages.

How It Works

  1. Setup: Configure departments with client types (KOC, WJO), set warning thresholds in Alert Settings
  2. Add Records: Create employee and vehicle records with basic information
  3. Submit Renewals: Use Document Renewal wizard to submit, reject, or issue document renewals
  4. Apply for Passes: Use Pass Applications wizard to manage field pass applications
  5. Monitor: Dashboard shows live status across all departments with clickable cards
  6. Track History: Full event log on every employee and vehicle record
